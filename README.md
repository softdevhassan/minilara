# Mini Lara - Professional Business Management Boilerplate (v1.1.0)

Mini Lara is a high-performance, lightweight PHP boilerplate designed for building customized business management systems (ERP, CRM, Inventory). It combines the simplicity of a custom framework with the power of industry-standard components from Laravel 13 and Symfony 7.

## Industry Standard Stack
- **Engine**: PHP ^8.3 (Optimized for 2026 standards)
- **Routing**: `nikic/fast-route` (The king of speed, used by Slim)
- **HTTP Layer**: `symfony/http-foundation` (Professional Request/Response handling)
- **Database**: `illuminate/database` (Eloquent ORM & Query Builder)
- **Validation**: `illuminate/validation` (Laravel's standard validator)
- **Logging**: `monolog/monolog` (Professional logging to files/slack/etc.)
- **CLI Engine**: `symfony/console` (Professional CLI for Database management)
- **Frontend**: Tailwind CSS 4 + Alpine.js + jQuery 4.0 + Axios + Chart.js

## Core Features
- **FastRoute Engine**: Extremely fast and flexible routing.
- **HttpFoundation**: Standardized Request/Response objects.
- **Native Blade v13**: Direct integration of the latest Laravel Blade engine.
- **Monolog Integration**: All system activities are logged professionally.
- **Dynamic Theme Engine**: Enterprise White, Royal Purple, and Noir presets.
- **Database Manager**: Professional CLI tool (`php ml`) for migrations and seeding.
- **Smart Installer**: Interactive setup for database and environment.

## Installation

```bash
composer create-project softdevhassan/minilara your-app-name
```
